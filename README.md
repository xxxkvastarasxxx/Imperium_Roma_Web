# Imperium Roma — Web

Статичний багатосторінковий сайт (HTML/CSS/JS без фреймворків) із невеликим
власним білд-пайплайном: спільні HTML-партіали (header/footer), мінімізація
CSS/JS/HTML та хешування імен файлів для кеш-бастингу.

Детальніше про архітектуру, партіали та деплой — у [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md).

## Вимоги

- Node.js **20+** (перевірити версію: `node --version`)
- npm (йде разом із Node.js)

## Встановлення

```bash
npm install
```

Встановлює dev-залежності (`browser-sync`, `chokidar`, `esbuild`, `lightningcss`,
`html-minifier-terser`), потрібні лише для локальної розробки й білду.

## Запуск локально

```bash
npm run dev
```

Піднімає локальний сервер із live-reload на **http://localhost:3000**. При
збереженні будь-якого файлу проєкт автоматично перезбирається і сторінка в
браузері оновлюється сама. Вивід у цьому режимі **не мінімізований і без
хешів** — зручно для дебагу.

Порт можна змінити змінною середовища:

```bash
PORT=4000 npm run dev
```

## Інші команди

| Команда | Що робить |
|---|---|
| `npm run dev` | Локальний сервер розробки з live-reload на `:3000`. |
| `npm run build` | Продакшн-білд у `dist/` — мінімізовані CSS/JS/HTML і файли з хешами в іменах. |
| `npm run preview` | Повний продакшн-білд + сервер, що віддає `dist/` як є (без watch) — перевірити реальний деплойний вивід. |
| `npm run clean` | Видалити `dist/`. |

`dist/` — це згенерована папка (у `.gitignore`), редагувати її вручну не треба.

## Структура

- Сторінки лежать у папках за URL-шляхом: `about/index.html` → `/about/`.
- Спільні header/footer підключаються директивою
  `<!-- @include partials/header.html -->` / `footer.html` і редагуються в
  одному місці — `partials/`.
- `domus/*` і `login/*` — окрема "особистий кабінет"-частина, яку планово
  замінює React-застосунок; не використовує спільні партіали.

Докладніше про додавання сторінок, оптимізацію асетів і деплой — у
[docs/DEVELOPMENT.md](docs/DEVELOPMENT.md).
